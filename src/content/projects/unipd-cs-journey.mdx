## What this is

An open-source archive of my Computer Science degree at the University of Padua, built progressively as I move through the programme. For every course I attend, the site collects what I produce: lecture summaries, exercise solutions, exam strategy notes, and anything else worth sharing. The goal is simple — make it all findable and readable, for me and for anyone taking the same courses.

The project lives at [stangauni.github.io](https://stangauni.github.io) and is maintained under the [`StangaUni`](https://github.com/StangaUni) GitHub organisation. Content is licensed under CC BY-NC 4.0.

## The site

Built with React, TypeScript, and Vite, with MDX for content. Tailwind CSS handles styling; KaTeX renders LaTeX math inline and in display blocks; React Syntax Highlighter covers code. Deployed automatically to GitHub Pages via GitHub Actions.

Notes are organised by subject, each with its own changelog and a structured list of files grouped by type (summaries, exercises, extra material). Each note page gets an auto-generated table of contents and breadcrumb navigation.

Six courses across both semesters of Year 1 (academic year 2025/2026).

## What's next

The current site remains live on GitHub Pages, but it runs against the constraints of a static host: no server-side logic, no dynamic content, no way to serve richer features at scale.

To remove those limits, I'm building a dedicated platform — **UniShelf** — using .NET Blazor and a custom API layer, built directly on top of [my own libraries](/portfolio/stanga-net-lib). The goal is to keep the open-source archive intact while offering a hosted version that is accessible to a wider audience, without depending on GitHub's infrastructure or its constraints.
