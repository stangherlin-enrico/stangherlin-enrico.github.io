## Context

An institutional website for an Italian company, conceived and built entirely by me — from initial design to production deployment. The company name and domain are withheld.

The project went through three distinct iterations, each replacing the previous one as requirements and hosting constraints evolved.

## V1 — Angular + Node.js, containerised

The first version was a full-stack containerised application. The frontend was built with Angular 17 and TypeScript, with Angular SSR enabled for static prerendering. The backend was a Node.js 20 / Express 5 API whose sole responsibility was handling the contact form: reCAPTCHA v3 verification, rate limiting (5 requests per 15 minutes per IP), and email delivery via Nodemailer with HTML-escaped input to prevent XSS. Both services were packaged as Docker containers behind a Caddy reverse proxy, with nginx handling internal routing.

## V2 — Static archive

An intermediate snapshot of compiled public pages, kept as a reference before the architecture changed.

## V3 — Astro + Sveltia CMS (current)

The current version is a fully static site generated with Astro 4 and TypeScript, deployed to shared hosting via GitHub Actions and FTP. The switch from a containerised stack was driven by hosting constraints: the target environment runs PHP on Aruba, with no support for Docker or persistent Node.js processes.

**Content management.** A Sveltia CMS instance at `/admin` allows non-technical editing of fleet and team data directly from the browser. Content is stored as JSON files in Astro Content Collections with Zod schema validation; saving triggers a Git commit, which kicks off the deployment pipeline automatically.

**Multilingual.** The site is available in Italian, English, and French. All copy is centralised in per-language JSON files; language switching is handled client-side via `localStorage`.

**Contact form.** A PHP handler processes form submissions server-side using the Brevo SMTP API. A honeypot field provides anti-spam protection without requiring a third-party challenge.

**Other features.** Google Analytics 4 (loaded post-cookie-consent), auto-generated sitemap, Open Graph tags, custom 404, and a fleet showcase with per-vehicle specs and category filtering.
